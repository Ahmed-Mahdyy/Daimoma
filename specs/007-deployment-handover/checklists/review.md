# Reviewer Checklist: Delivery

Created: 2026-09-20. Owner: product/operations/security reviewer. Approval concerns requirement quality, not completed deployment.

- [ ] CHK001 Are public application and private database/storage boundaries unambiguous? [Clarity, Spec FR-001]
- [ ] CHK002 Are configuration, immutable build, health, migration, and promotion failure rules defined? [Completeness, Spec FR-002/FR-003]
- [ ] CHK003 Are backup scope, retention, recovery objectives, isolated restore, and rollback constraints explicit? [Coverage, Spec FR-004]
- [ ] CHK004 Are safe observability, dependency failures, and operational ownership specified? [Completeness, Spec FR-005]
- [ ] CHK005 Are demo data disclosure, non-overwrite seeding, and credential delivery rules defined? [Clarity, Spec FR-006]
- [ ] CHK006 Are all deliverables, reproducibility, AI evidence, rubric/stage review, and freeze obligations traceable? [Traceability, Spec FR-007/FR-008]

A planning approval does not authorize provisioning, payments, publishing, destructive actions, or a production deployment.
