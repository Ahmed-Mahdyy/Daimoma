# Reviewer Checklist: Requests

Created: 2026-09-20. Owner: product/security reviewer. Approval evaluates requirements, not implementation.

- [ ] CHK001 Are category fields, validation, and draft ownership explicit? [Clarity, Spec FR-001]
- [ ] CHK002 Are file privacy, limits, quarantine, scan failure, and editability specified? [Coverage, Spec FR-002]
- [ ] CHK003 Are both approval routes, fallback, self-approval denial, and reasons unambiguous? [Completeness, Spec FR-003/FR-004]
- [ ] CHK004 Is historical content/route retention consistent with resubmission and type changes? [Consistency, Spec FR-005/FR-009]
- [ ] CHK005 Are duplicate/stale actions and reporting-line reassignment outcomes specified? [Coverage, Spec FR-006]
- [ ] CHK006 Are history, notification, search/count/file scopes consistent? [Consistency, Spec FR-007/FR-008]
- [ ] CHK007 Are all responsive/error/accessibility and acceptance outcomes testable? [Measurability, Spec FR-010]

D-006 confidentiality is an explicit gate, not permission to expose sensitive HR requests to a manager by default.
